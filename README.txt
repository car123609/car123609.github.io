TORNADO SANDBOX - ONEHUD STYLE LOADING SCREEN
=============================================

Contents
--------
index.html
style.css
config.js
loading.js
assets/tornado-sandbox-background.png
fonts/geologica.ttf

Installation
------------
Keep the folder structure intact and use index.html as the Garry's Mod loading
screen page.

Preview
-------
Open index.html?preview=1 in a browser to see simulated server details,
downloads and loading progress.

Configuration
-------------
Edit config.js to change the fallback server name, tagline, loading tips or tip
rotation interval.
